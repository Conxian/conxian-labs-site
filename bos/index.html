Business Operating System

The public-safe operating model for Conxian

The BOS is Conxian's machine-ingestible knowledge graph, framework, and research-cycle operating model. It is the canonical coordination surface for ecosystem inventory, gap mapping, comparable scoring, selection, implementation traceability, and evidence review — public-safe by design, with restricted legal, financial, identity, custody, and credential material kept out of Git.

Canonical BOS repository Operating model

Domain Separation Firewall

The BOS enforces a strict boundary between the developer protocol surface and the corporate governance surface.

conxian.org — Protocol

Developer surfaces: nexus, gateway, sdk, platform, market, wallet. No SLA; community best-effort support.

conxian-labs.com — Governance

Corporate surfaces: www, bos, api, status. The BOS lives here as the public governance entry point.

Operating Model

The public-safe research-cycle lifecycle. GitHub Issues, PRs, and the authorized organization Project are the coordination surface.

inventory → gap map → score → selected initiative → implementation/evidence → review → next-cycle refresh
  • One authority issue owns each cycle; existing implementation and acceptance trackers remain authoritative for their scope.
  • Public-safe artifacts at each phase gate: authority issue, verified gap statement, 100-point rubric scores, selection decision, implementation evidence.
  • Restricted material (legal, financial, identity, custody, recovery, secrets, PII) never enters Git, issues, PRs, or Projects.

Knowledge Framework

Agentic-first, machine-readable knowledge architecture (Version 4.5) designed for AI consumption and autonomous action.

Structured over prose

YAML/JSON tables and typed entities with created, updated, version, and status.

Query-first mapping

Agent questions map directly to sections (CI failures, secrets, ownership, decisions, vulnerabilities, deployments).

Cross-referenced

Relations link entities across repositories, decisions, vulnerabilities, and deployment surfaces.

Canonical BOS documents

Single source of truth lives in the conxian-business repository.

  • Knowledge Graph — live topology, session updates, and decisions.
  • Knowledge Framework — the machine-readable entity schema and query mapping.
  • Operating Model — the public-safe research-cycle lifecycle and phase gates.
  • Research Candidate Ledger — the scored candidate registry.
  • Implementation Reconciliation — current dated coordination and phase map.
