Ecosystem Components

  • conxian-market: Active market, liquidity, and asset execution engine supporting institutional settlement and order routing.
  • Conxian Gateway: Beta and pilot-first integration surface for local discovery, verification, and workflow rehearsal.
  • Conxius Wallet: Stable, non-custodial, Android-first reference client for demo and integration-to-launch work.
  • Conxius Enclave SDK: Beta/conditional builder surface for enclave, signing, attestation, and key-management boundaries.
  • lib-conxian-core: Live shared foundation with stable API and fail-closed verification boundaries; not a paid tier.
  • Deprecation Notice: The legacy monolithic Conxian/Conxian repository is deprecated in favor of modular domain repositories (conxian-market, conxian-gateway, conxian-nexus).
