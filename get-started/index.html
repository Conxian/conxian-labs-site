The journey

Four steps, start to production.

Choose a plan

Pick a managed tier below, or start on the free open-source software. See pricing for units, terms, and boundaries.

Pay with Lightning

We create a Lightning invoice on the gateway. Pay it from any wallet; the site never sees your payment.

Claim your key

Once the gateway confirms settlement, it mints your managed API key. It is shown once — store it then.

Go live and monitor

Point your agent at the managed endpoint and watch the public status page. Request a console account to change or cancel.
