Institutional Background

Conxian Labs

Conxian Labs is the builder and operator layer around the broader Conxian ecosystem. We are a South African engineering organization (CONXIAN LABS) focused on sovereign infrastructure, cryptographic primitives, and institutional-grade tooling for the Bitcoin and Stacks ecosystem.

Company details: CONXIAN LABS · Enterprise No. K2026884014 · South Africa.

Mission

We build, operate, and support the public surfaces that make the Conxian ecosystem understandable, usable, and easier to adopt — without replacing protocol ownership or custody.

Sovereign by Design

Every component we ship runs under the user's control. No custodial shortcuts, no hidden signing authority. The SDK, gateway, and enclave tooling are all built for self-sovereign operation.

Open Source First

Core infrastructure is MIT-licensed. Paid scope is strictly limited to hosted operational services and enterprise support layers. The protocol boundary is public and auditable.

Institutional Engineering

We apply institutional-grade engineering standards — formal verification, reproducible builds, audit-ready documentation — to every production surface we operate.

Ecosystem Portfolio

Conxian Labs maintains the following public infrastructure and tooling surfaces:

Conclave SDK

Rust-based cryptographic primitives with MuSig2, Schnorr, Taproot, and BitVM support. Hardware provider integration (Android StrongBox, Apple Secure Enclave, HSM) is a qualification target, not currently production-supported.

Conxius Wallet

Flagship mobile application implementing the SDK for local-first sovereign key management.

Conxian Gateway

Rust-based gateway bridging application requests to protocol actions; a Beta integration surface for local and pilot-first evaluation.

Conxian Nexus

Source-available proof and state-observation surface (BUSL-1.1), deployed at nexus.conxian.org. Readiness is reported honestly on the status page.

Conxius Platform

Operational dashboard and monitoring surface for node operators and infrastructure providers.

Enclave SDK

Secure enclave orchestration toolkit exposing enclave, key-management, signing, and attestation interfaces. Production hardware-backed signing is not claimed.
