Developer Package

Open SDK, optional paid hosting

/sdk is the canonical developer entry. The SDK itself is open and freely accessible; paid offerings are hosted operational services layered on top. Conxian Labs is the builder and operator layer for the Conxian ecosystem, providing software, infrastructure, and services. Conxian Labs provides these services, while custody and signing remain with users and organizations. Conxian Labs does not hold customer funds or custody user assets.

Package boundary clarity

Protocol and core SDK remain open-source under the Conxian ecosystem context. Commercial scope covers Labs-hosted infrastructure and contracted support only, without taking custody or signing control from users.

Open

SDK source and local integration

Build, test, and run against the SDK without purchasing a license for the SDK itself.

Usage-based

Hosted service acceleration

Use managed APIs, relay capacity, and operational tooling when you prefer a hosted path.

Contracted

Enterprise and sovereign support

Add SLAs, architecture reviews, and commercial support agreements for production programs.

SDK download/use is not a paid SKU. Paid scope starts at hosted services or contracted support, and does not transfer custody of funds or user assets to Conxian Labs.

Hosted Service Configuration

When using hosted Conxian Labs infrastructure, use the following service endpoints in your SDK configuration.

{ // gateway_url "gateway_url": "https://gateway.conxian-labs.com", // kms_endpoint (optional) "kms_endpoint": "https://vault.conxian-labs.com", // nexus_url (optional) "nexus_url": "https://nexus.conxian-labs.com", "api_key": "your-api-key" }
Replace your-api-key with your active Conxian Labs API key from your dashboard.
