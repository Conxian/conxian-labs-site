Conxius Enclave SDK

The Conxius Enclave SDK is a Beta/conditional open-source builder surface for cross-platform enclave and key-management boundaries, secure signing, and attestation interfaces. Review the canonical repository and current evidence before relying on any capability; production readiness and provider enablement are not claimed here.

View SDK source Integration Guide

Package boundary clarity

The canonical repository keeps reusable security-sensitive boundaries separate from higher-level applications and services. Treat this SDK as Beta/conditional and review the current source and evidence before integration.

Boundary

Cross-platform enclave and key-management boundaries

The repository provides reusable enclave and keystore abstractions plus key-lifecycle controls for higher-level applications and services. Review runtime and provider boundaries before integration.

Interface

Secure signing

Signing primitives and secure key-handling interfaces are in scope for local development and integration work. Do not infer value-bearing production enablement from these interfaces.

Interface

Attestation interfaces

Attestation and trust-reporting interfaces are present. The canonical repository documents simulated evidence and does not establish vendor-backed production support.

The canonical repository is MIT-licensed. Review its current source, capability matrix, and readiness evidence for supported integration paths.
